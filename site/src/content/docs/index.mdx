## Capture → Upload → Process → Explore → Export

StreetView combines an Android capture app and a self-hosted portal. Import the recording as a ZIP or a matching MP4 and LOG, check GPS quality, and extract photos linked to locations. Explore the route, correct points, and export GIS files.

The portal is an alpha with one administrator and one worker. The verified deployment target is Docker Desktop with Linux amd64 containers.
