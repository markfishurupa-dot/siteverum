---
title: Publish a map
---

Choose route, points, or both, and select a default basemap. Select **Publicly available** only when visitors who can reach the server may view the survey without signing in. Select **Publish locally**, then **Open published map**. The workspace and export downloads require administrator access.

Choose **Update published map** or **Republish map** to apply edits or new settings. A green dot indicates a current published run; yellow indicates newer source data or results. Unpublish revokes access.

The default server address is bound to localhost. Sharing with other devices requires separately configured network access and secure HTTPS and authentication appropriate to the deployment. OpenStreetMap tiles are requested from its servers when selected.
