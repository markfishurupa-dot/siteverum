# Contributing

Thank you for helping improve SiteVerum. Open an issue to discuss substantial changes, then create a focused branch and describe the problem, approach, and verification in your pull request.

Run the Python tests with `python -m unittest discover -s tests -v`. Build the documentation with `npm ci --prefix site` and `npm run build --prefix site`. Build the Android debug app from `apps/android` using the Gradle wrapper. See the Android README for requirements.

Do not include private recordings, location data, credentials, signing keys, or generated APKs. Contributions are distributed under the repository's AGPL-3.0-only license. Third-party material must have compatible rights and attribution.
