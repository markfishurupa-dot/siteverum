# SiteVerum Portal 2.1 and Android 1.3.1

SiteVerum 2.1 adds processing modules to the local survey portal. Install a trusted module ZIP, select it under **Additional Processing**, and open the results in the survey that produced them. The portal also adds logout and fits the published map, photos and navigation to the browser viewport.

- **Survey QA 1.0.0** reports exported frame counts, missing GPS bearings and optional breakdowns by recording.
- **Electrical Poles Detection 1.1.0** locates utility poles from multiple georeferenced photographs. It supports CPU and optional NVIDIA CUDA, custom YOLO models and label mappings, photo evidence, coordinate edits, manual additions, review states and GIS exports. Temporary map reviews can be downloaded as GeoJSON.
- **Android 1.3.1** refreshes the capture dashboard, recordings list and camera alignment preview. For road-focused surveys, move the horizon higher in the preview. For poles or other tall assets, move it lower so the tops stay in frame.

## Downloads and setup

- `SiteVerum-1.3.1.apk` is the signed Android installer. The [Android source](https://github.com/markfishurupa-dot/streetview-v2/tree/v2.1.0/apps/android) and [illustrated capture guide](https://markfishurupa-dot.github.io/streetview-v2/start/android/) are available online.
- `streetview-survey-qa-1.0.0.zip` installs through **Modules → Install ZIP**.
- Use the GitHub source archive or clone the repository for the [portal setup](https://markfishurupa-dot.github.io/streetview-v2/start/install/). Follow [Processing modules](https://markfishurupa-dot.github.io/streetview-v2/modules/) for the module-enabled Docker stack, illustrated walkthroughs and custom module development.
- `streetview-poles-detection-1.1.0.zip` installs through **Modules → Install ZIP**. [Module source](https://github.com/markfishurupa-dot/streetview-v2/tree/poles-detection-v1.1.0/modules/poles-detection)
- `pole_yolo11s_best.pt` provides the default four-class pole model. Mark Urupa fine-tuned Ultralytics **YOLO11s** (`yolo11s.pt`) using internally captured and labeled imagery. The checkpoint is published under AGPL-3.0. [Model attribution, checksum and training configuration](https://github.com/markfishurupa-dot/streetview-v2/blob/poles-detection-v1.1.0/docs/models/pole-yolo11s.md)
