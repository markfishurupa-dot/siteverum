# StreetView 2.0 - v2.0.0-alpha.6

**Self-hosted road survey processing and field imagery exploration**

This is an **alpha prerelease** of the StreetView 2.0 portal, paired with the separately versioned **StreetView Android 1.3.0** capture app.

**[Live read-only demo](https://markfishurupa-dot.github.io/streetview-v2/demo/)** · **[Documentation](https://markfishurupa-dot.github.io/streetview-v2/)** · **[Source repository](https://github.com/markfishurupa-dot/streetview-v2)**

## What works

- Android video/GPS capture source with matching MP4/LOG files and session ZIP export
- Secure upload, source validation, GPS accuracy warnings and downloadable validation reports
- Frame sampling by GPS fix, time interval or distance
- Asynchronous survey processing using FFmpeg, PostgreSQL/PostGIS and persistent media storage
- Interactive route map and georeferenced photograph navigation
- Multiple recordings per survey, preserving individual route segments
- Corrections to point coordinates and bearings, photo rotation, point removal and revision-aware published maps
- Downloadable JPEG images, GeoPackage, GeoJSON, CSV and portable survey ZIP
- Administrator-authenticated workspace and optional read-only published map with configurable visitor access

## Install the portal with Docker

**Verified environment:** Windows Docker Desktop using Linux amd64 containers, with Docker Compose available. Native Linux clean-install and backup/restore are not yet fully verified.

1. Install [Docker Desktop](https://docs.docker.com/desktop/setup/install/windows-install/) and Git, and start the Linux Docker engine.
2. In PowerShell:

```powershell
git clone https://github.com/markfishurupa-dot/streetview-v2.git
cd streetview-v2
.\setup.ps1
```

3. Open **http://127.0.0.1:18080/**.
4. Sign in as `admin` with `SV_ADMIN_PASSWORD` from the local `deploy/.env` file generated on first setup.

Linux users with Docker Engine, the Compose plugin, Git and OpenSSL can run `bash ./setup.sh`. The environment file and Docker volumes must be preserved across restarts. Read the [full installation guide](https://markfishurupa-dot.github.io/streetview-v2/start/install/) before upgrades or network exposure.

**Release-gate notice:** A signed APK is **not downloadable from this draft release until the exact verified file is attached as an asset**. Verify that the published asset's SHA-256 matches the above value before installing. Physical-device test evidence for this exact SHA-256, prior-install update compatibility and final distribution approval remain to be confirmed.

Once the verified APK asset is attached and approved: download it from the official GitHub Release, review the Android install prompts, grant camera and precise location permissions, record a short route, then export a ZIP or matching MP4/LOG files and upload them into the portal. Do not uninstall an earlier version before backing up recordings.

For technical evidence see [APK verification](https://github.com/markfishurupa-dot/streetview-v2/blob/codex/alpha-implementation/docs/apk-v1.3.0-verification.md) and [Android capture instructions](https://markfishurupa-dot.github.io/streetview-v2/start/android/).

## Limitations and safety

- Alpha supports one administrator and one processing worker; large-scale multi-user operation is not certified.
- The default Compose stack binds to `127.0.0.1`. Anonymous viewing of a **published** survey does not itself expose the server to the Internet.
- Original source recordings and survey data are kept in persistent Docker volumes. Deleting a survey currently soft-deletes it and does not securely erase the source assets.
- The GitHub Pages demo uses **real survey photos and geospatial coordinates**. Dataset reuse terms and privacy review must be confirmed separately from the software license.
- Third-party container-image redistribution, backup/restore and physical-device Android checks remain documented release gates.
- Machine learning / pole detection is not included in this release.
